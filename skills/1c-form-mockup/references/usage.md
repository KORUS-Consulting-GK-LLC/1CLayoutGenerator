# Команды и форматы

Каждая команда вызывается как `python <skill-dir>/scripts/form_html.py <command> ...`
и печатает JSON в stdout. Пути задаёт вызывающий проект.

## Исходная форма

```text
find --src <dump> --object "Документ.ЗаказКлиента"
outline --src <dump> --form <Form.xml>
extract --src <dump> --configuration demo-erp --form <Form.xml> --profile none --out mockups/form.json
```

Поддерживаются русские/английские виды объектов, включая общие формы. Для
extract/build/outline корень может следовать из стандартного пути Form.xml;
при явном `--src` форма обязана находиться в этом dump. Find без `--src` ищет
`src` в текущей рабочей папке, не рядом с установленным skill. В многоконфигурационном
проекте задавайте источник явно. `--configuration` разделяет профили, а не
переключает фактически указанный источник. `--product "Приложение"` меняет подпись
оболочки; по умолчанию «1С:Предприятие». JSON может задавать `section`/`sections`.

## Профиль видимости

XML не знает функциональные опции и пользовательские настройки. Профиль
описывает наблюдаемую форму, например:

```json
{"source":"Скриншот предоставленной формы, дата",
 "tabs":["Основное","Товары"], "buttons":["*Записать и закрыть","Записать"],
 "tables":{"Товары":{"columns":["N","Номенклатура","Цена"],"cut":true}},
 "table_buttons":{"Товары":["Добавить","Подбор"]}}
```

Без профиля `--profile auto` возвращает exit3 с `profile_to_write`. По умолчанию
это `<родитель dump>/.1c-form-mockup/profiles/<configuration>.<Folder>.<Object>.<Form>.json`.
Область включена всегда, включая `default`. `extract/build --profiles-dir <folder>`
выбирает другое хранилище. Источник/путь профилей сохраняются в JSON.

`--profile <file>` выбирает явный профиль: проверьте его конфигурацию, форму и
актуальность. `--profile none` означает предложение по XML, не подтверждённый
внешний вид базы. При `cut: true` невидимый край не считается отсутствующим.
Объединение наблюдений: `merge-profile first.json second.json --out profile.json`.
Подробные ключи/поведение — form-elements.md.

## Изменения

```text
add --json mockups/form.json --kind column --title "Скидка, %" --after Цена --table Товары
add --json mockups/form.json --kind field --title Склад --after Клиент --choice
add --json mockups/form.json --kind checkbox --title Проверено --after Склад
add --json mockups/form.json --kind button --title Пересчитать --table Товары
add --json mockups/form.json --kind tab --title Резервы --after Товары
mark --json mockups/form.json --title Цена --table Товары --note "Пересчитывается после выбора склада"
```

Field/checkbox требуют `--after`. Если заголовок не найден, команда подсказывает
близкие варианты. Add/mark меняют только JSON, не метаданные. Для новой формы:
`extract ... --new-form` с базовой формой либо синтетический JSON с `new_form: true`.
Группы/состав можно менять в JSON вручную; результат остаётся предложением.

## Данные и результат

```json
{"fields":{"Клиент":"Демонстрационный клиент"},
 "choices":{"Склад":["Пример склада"]},
 "tables":{"Товары":[{"Номенклатура":"Пример","Цена":"100,00"}]}}
```

```text
render --json mockups/form.json --data sample.json --out mockups/form.html
build --src <dump> --configuration demo-erp --form <Form.xml> --profile none --new-form --out mockups/new.html
```

CSS/JS внутри HTML, внешние библиотеки/шрифты не загружаются. Это имитация
вкладок/выбора/таблиц без бизнес-кода1С. Системные шрифты и клиент могут отличаться;
пиксельное совпадение с1С не обещается.

Вывод: `html`, `link`, `layout`, `highlight`, возможные `warning`. Отсутствующий
элемент с изменением нельзя объявить показанным. До5изменений — рамки сразу,
больше5 — по выбору пункта. Новая форма без рамок. `--no-shell` убирает оболочку.

`--open` открывает HTML по выбору пользователя. `--png` сохраняет изображения
через headless браузер, `--png-size 1400,1000` задаёт размер. Вложенные вкладки
снимаются с открытыми родителями. Берите имена из `png`; `png_warning` означает
ошибку изображения, а не автоматически ошибку HTML.

Exit0 — команда выполнена (проверьте предупреждения), exit2 — ошибка/не найден
объект/параметр, exit3 — нужен профиль или выбор XML-only. Argparse также использует2.

Word/БП/ЗНР подключает потребляющий проект. Встроенного DOCX-конвертера,
сохранения в СППР и специальных embed-маркеров в переносимом skill нет.

# Повторное ревью перед публикацией — 21 октября 2026

Проверены Python HTML-движок и CLI, встроенные CSS/JS, ручной capture helper,
разделение конфигураций и профилей, PNG-маршрут, проверка manifest, тесты,
инструкции установки и новые инструменты репозитория.

## Найдено и исправлено

| Проблема | Исправление и проверка |
|---|---|
| CLI мог перезаписать исходный Form.xml или собственный JSON через --out | Запрет записи в исходный XML-dump и поверх входных файлов; проверены неизменные байты |
| Неверный JSON/неподходящий XML приводил к traceback либо пустому «макету» | Проверка структуры формы и managed Form.xml, понятные JSON-ошибки и exit2 |
| Ссылка метаданных могла выйти за выбранный dump | Проверка канонического пути; отдельный отрицательный тест |
| Явный --profile игнорировался, если JSON уже был извлечён | Явный профиль применяется независимо от сохранённого profile_report |
| PNG мог считаться готовым при ошибке браузера; старый файл удалялся до успеха | Проверка exit/file, временный кандидат и замена только после успешной проверки; отрицательные и положительный тесты с подменённым процессом |
| Высокая форма незаметно обрезалась на 8000px | Предупреждение с предложением явного размера вместо ложного полного снимка |
| Пустой/неправильный manifest проходил либо давал traceback | Проверка структуры, путей и SHA; явный отказ |

13 регрессионных случаев сначала воспроизведены на прежнем пакете; после
исправления прошли вместе с сохранёнными тестами исходного генератора.
Новые repository-тесты проверяют demo из другой CWD, установку/повтор/сохранение
локальных правок и соответствие ZIP исходникам.

## Границы результата

Backend проверен локально на Windows/Python3.13. Поддержка синтаксиса3.9
проверяется отдельно. CI настроен на Linux/Windows/macOS; его конкретный статус
нужно смотреть во вкладке Actions, наличие workflow не означает успешный прогон.

Локальный результат: **63 успешно, 1 пропущен** (настоящий браузер):
59 случаев компонента, включая13регрессий, и5проверок инструментов репозитория.

Настоящий браузер и PNG/UI автоматически не запускались. Проверки PNG здесь
используют подмену subprocess; они доказывают обработку результатов/ошибок,
но не визуальное сходство. Составные элементы и неизвестные виды XML остаются
приближением: при warning требуется разбор, нельзя выдавать его за успешную
реализацию. Функциональное поведение1С не воспроизводится.

Публичный состав не содержит исходников конфигурации, профилей заказчика,
локальных абсолютных путей, ключей или внутренних адресов сервисов.

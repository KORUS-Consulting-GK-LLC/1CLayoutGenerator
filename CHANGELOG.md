# Изменения

## 1.1.0

Первый самостоятельный выпуск 1C Layout Generator на GitHub.

- Простой `python layout.py demo`, установка skill и сборка ZIP из репозитория.
- Валидация входного JSON и managed Form.xml, ошибки CLI вместо traceback.
- Защита XML-dump и входного JSON от перезаписи результатом.
- Ограничение чтения метаданных выбранной выгрузкой.
- Исправлено игнорирование явно заданного профиля при повторном render.
- PNG: проверка exit/file, атомарная замена после успеха, сохранение старого PNG
  при сбое, предупреждение вместо незаметного обрезания слишком высокой формы.
- Проверка структуры manifest и новые регрессионные тесты.
- Подготовка публичного состава без внутренних адресов/профилей/данных проекта.

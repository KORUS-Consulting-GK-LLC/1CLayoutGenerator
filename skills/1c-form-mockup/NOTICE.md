# Происхождение

Выделен из проектного компонента `ui-mockup`,
ревизия `ec9e5f92d27cc50fbefe22f4c81ddca935de1588` (исправленная проектная версия).
История компонента включает работу Артёма Дворникова; проектные исправления
опубликованы от DenisAndronov. Сохранены HTML-движок, CSS/JS, операции JSON
и исправления вложенных вкладок. Новая упаковка не назначает исходному коду
новую лицензию. Самостоятельный пакет поддерживается в 1CLayoutGenerator.

Первый самостоятельный выпуск 1.1.0 — 21.10.2026, исходные хеши — ORIGIN.json.

Изменения: произвольные области конфигураций, рабочие пути независимо от harness,
нейтральная оболочка, корректные file URI, чтение JSON с закрытием файлов/BOM,
независимые инструкции SKILL.md, opt-in браузерные тесты, manifest и проверки переноса.

Не включены реальные профили заказчика, выгрузка КА, доступы, интеграция СППР/Word
и обработчик редактирования растровых скриншотов. Пример и XML в тестах синтетические.
Это макеты управляемых форм, не произвольные печатные HTML-макеты и не изменения ИБ.
